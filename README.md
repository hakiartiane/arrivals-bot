# Бот-рассылка о поступлениях

Клиенты подписываются командой `/start`, выбирают тип прайса (Белый / Общий).
Вы пишете боту сообщение, видите превью и подтверждаете — оно уходит нужному
сегменту подписчиков.

## Как это работает

- Клиент переходит по ссылке на бота, жмёт **Start**, выбирает интересующие прайсы (можно оба) → добавляется в базу подписчиков
- **Белый прайс** — рассылка уходит абсолютно всем подписчикам, независимо от выбора
- **Общий прайс** — уходит только тем, кто явно отметил этот вариант при подписке (клиенты "только безнал" его не получают)
- Клиент может отписаться командой `/stop`
- База хранится в Supabase (Postgres) — не теряется при обновлении бота на Render

## Команды

**Для клиентов:**
| Команда | Действие |
|---|---|
| `/start` | Подписка и выбор типа рассылки |
| `/stop` | Отписка |

**Для вас (админ, только с вашего ADMIN_ID):**
| Команда | Действие |
|---|---|
| `/help` | Список команд |
| `/white` | Начать рассылку по Белому прайсу (всем) |
| `/common` | Начать рассылку по Общему прайсу (только сегмент) |
| `/all` | Начать рассылку абсолютно всем |
| `/stats` | Статистика подписчиков |
| `/export` | Выгрузить базу в CSV |
| `/block <chat_id>` | Заблокировать подписчика |
| `/unblock <chat_id>` | Разблокировать подписчика |
| `/cancel` | Отменить текущее действие |

После `/white`, `/common` или `/all` пришлите текст/фото/документ — бот покажет
**превью** и попросит подтвердить кнопкой «✅ Отправить» перед реальной рассылкой.

## Шаг 1 — создать бота у BotFather

1. В Telegram откройте `@BotFather`
2. Отправьте `/newbot`, следуйте инструкциям, задайте имя
3. Получите **токен** — длинная строка вида `123456:ABC-DEF...`
4. Поставьте своё фото аватаром бота через `/setuserpic` в BotFather

## Шаг 2 — узнать свой Telegram user ID

1. Напишите боту `@userinfobot` — он пришлёт ваш числовой ID
2. Это значение пойдёт в `ADMIN_ID`

## Шаг 3 — создать бесплатную базу данных на Supabase

Это решает проблему "база слетает при каждом обновлении бота" — данные
хранятся отдельно от Render и не зависят от передеплоев.

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите через GitHub
2. **New Project**: задайте имя (например `arrivals-bot`), придумайте пароль базы данных (**сохраните его** — понадобится в следующем шаге) и выберите ближайший регион
3. Дождитесь создания проекта (1-2 минуты)
4. Зайдите в **Project Settings** (шестерёнка внизу слева) → **Database**
5. В разделе **Connection string** выберите вкладку **URI** — скопируйте строку вида:
   ```
   postgresql://postgres:[YOUR-PASSWORD]@db.xxxxxxxxxxxx.supabase.co:5432/postgres
   ```
6. Замените `[YOUR-PASSWORD]` на пароль, который вы задали в шаге 2 — это и есть значение `DATABASE_URL`

## Шаг 4 — настроить переменные окружения

Скопируйте `.env.example` в `.env` и заполните:
```
BOT_TOKEN=токен_от_botfather
ADMIN_ID=ваш_id
DATABASE_URL=строка_подключения_из_supabase
```

## Шаг 5 — запуск

**Локально (для теста):**
```bash
pip install -r requirements.txt
python bot.py
```

**На хостинге (Render — постоянная работа 24/7):**

1. Загрузите все файлы в GitHub-репозиторий, включая `.python-version` (фиксирует Python 3.12 на Render)
2. На Render.com нажмите **New → Web Service**, выберите этот репозиторий

   Важно: выбирайте именно **Web Service**, а не Background Worker
3. Настройки сборки:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
4. В разделе **Environment** добавьте три переменные: `BOT_TOKEN`, `ADMIN_ID`, `DATABASE_URL` (значение `PORT` Render подставит сам)
5. Нажмите **Create Web Service** и дождитесь деплоя. Render выдаст публичный адрес вида `https://ваш-бот.onrender.com`

**Подключение UptimeRobot** (чтобы бесплатный тариф Render не "засыпал"):

1. Зарегистрируйтесь на [uptimerobot.com](https://uptimerobot.com)
2. **Add New Monitor** → Monitor Type: **HTTP(s)** → URL: адрес из Render → Monitoring Interval: **5 minutes**
3. Сохраните — проверить работу можно, открыв URL в браузере: должна появиться надпись `OK`

## Шаг 6 — приглашение клиентов

Отправьте клиентам сообщение вида:

> Чтобы получать уведомления о новых поступлениях первыми — подпишитесь на бота: t.me/ваш_бот_username
> Просто нажмите Start, выберите интересующий прайс — и всё, рассылка будет приходить сюда.

## Важно

- Не рассылайте слишком часто — 1-3 сообщения в день оптимально
- Supabase на бесплатном тарифе может "засыпать" при полном отсутствии обращений ~1 неделю — раз в несколько дней бот обращается к базе сам (при подписках/рассылках), так что для активно используемого бота это не проблема
- `/export` по-прежнему полезен как ручной бэкап на всякий случай
